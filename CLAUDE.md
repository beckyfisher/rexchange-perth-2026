## 1. What this project is

A **talk repository**, not an R package and not a research compendium. It contains the
abstract, slides, speaker notes and reproducible figure code for a conference
presentation.

**Event:** R Exchange Perth 2026, 14–15 October 2026, Perth CBD.
Organised by [Epi](https://epi.group) (B Corp, Posit Professional Services Partner).
Day two, **session three: "real-life applications"** (2:30–4:10pm).

**Audience:** open-source data science professionals — R and Python users across
disciplines, interested in open science. Event themes include data visualisation, AI
integration, automated reporting, dashboarding, and open-source workflows in enterprise.
Assume they are technically strong and know nothing about ecotoxicology.

**Speaker:** Dr Rebecca Fisher, quantitative ecologist / ecological risk assessment
modeller, Australian Institute of Marine Science (AIMS).

**Talk length:** built for **20 minutes**; a 15-minute cut is marked in the deck and in
`notes/slide-outline.md`. (The original brief said 15 minutes in one place and 20 in
another — do not "fix" this by deleting one path.)

### Rendering

```powershell
& "C:\Program Files\R\R-4.5.1\bin\Rscript.exe" R/figures.R
& "C:\Program Files\Positron\resources\app\quarto\bin\quarto.exe" render
```

Figures are generated by a **standalone script**, not by executable chunks in the `.qmd`.
This is deliberate: it keeps slide rendering fast and dependency-free, so the deck can be
rebuilt on a machine that has Quarto but not `ssdtools`/`brms`. Regenerate figures only
when the underlying code changes.

### Packages in use

No `DESCRIPTION`. The canonical dependency list is the `library()` block at the top of
`R/figures.R`: `ggplot2`, `dplyr`, `tidyr`, `tibble`, `scales`, `patchwork`, `ssdtools`.
Ask before adding to it.

## 3. Content rules

- **The science is the setting, not the subject.** This audience came for open source and
  tooling. Ecotoxicology detail earns its place only when it makes a software point.
- **Reuse concepts from the earlier decks, never the slides.** `notes/source-synthesis.md`
  records what may be reused and what must not be repeated. Read it before editing content.
- **Preferred terminology is listed in `notes/source-synthesis.md` §"Preferred
  terminology".** Match it exactly — particularly `"no effect"` in scare quotes, "guideline
  values", "fit-for-purpose", and the blood-alcohol analogy for a DGV.
- **Visual style:** sparse text, one idea per slide, build up in layers with reveal.js
  fragments, `→` as the connector, schematic redraws rather than screenshots.
- **Every factual claim must be traceable** to `notes/source-synthesis.md` or the CV. Do
  not invent download counts, dates, productivity multipliers or quotes. Where a figure is
  illustrative rather than measured, label it "illustrative" on the slide itself.

## 4. Confidentiality

Some underlying work uses **confidential industry data** ("black literature" — the
speaker's own term). Nothing in this repo may contain raw industry data, client-identifying
monitoring results, or unpublished figures from commercial reports. Only use results that
are already in the public record via the listed publications.

The repo is **private**. Publisher PDFs (`Relevant_publication_history_pdfs/`) and the
large source `.pptx` files are `.gitignore`d — for copyright and repo size. Do not commit
them, and do not propose making the repo public without asking.
